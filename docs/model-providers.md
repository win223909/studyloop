# Model provider directory / 模型服务商目录

[Configuration guide / 配置指南](configuration.md) · [English README](../README.md) · [中文说明](../README.zh-CN.md)

StudyLoop includes **45 service and region presets**, plus a custom-service entry. In **Models & settings / 模型与设置**, search by Chinese or English provider name or browse China mainland, international, and local/self-hosted groups. Select the platform and region where your API account is enabled, then enter the model ID yourself.

内置 **45 个服务与区域预设**，另有自定义入口。在“模型与设置”中可按中英文服务商名称搜索，也可按国内、国际、本地与自托管分组浏览。先选择 API 账户开通的平台与地域，再自行填写模型 ID。

This directory matches [the application catalog](../src/model-providers.js), reviewed against linked official documentation on **2026-09-07**. It is an endpoint reference, **not a claim that every provider or model has been tested live**. Availability, billing, model permissions, JSON support, and output limits depend on the selected service and account. Group labels describe the directory, not a data-residency guarantee.

目录与[应用配置目录](../src/model-providers.js)一致，官方文档核对日期为 **2026-09-07**。它说明如何配置端点，**不代表逐服务商、逐模型实测通过**。可用性、费用、模型权限、JSON 支持和输出上限以具体服务与账户为准；目录分组不等于数据存储地域保证。

## Reading the directory / 使用方式

- Copy the **base URL**, not a browser chat address. StudyLoop adds the protocol endpoint; do not append `/chat/completions`, `/messages`, or `/models/...:generateContent` yourself. / 填写 API 根地址，不要重复添加具体接口路径。
- Model names are not interchangeable across platforms. Preserve organization prefixes, capitalization, and deployment IDs. Mainland and international credentials may belong to different accounts. / 模型 ID 按对应平台完整填写，保留组织前缀、大小写或部署名称；国内与国际密钥分别配置。
- `openai-compatible` sends Bearer authentication and non-streaming Chat Completions with system/user messages. `anthropic` and `gemini` use their native APIs. / 兼容模式使用 Bearer、非流式对话及 system/user 消息，另两类使用原生接口。
- For manual configuration, apply any listed `LLM_TOKEN_PARAMETER` override. The default `auto` uses `max_completion_tokens` for the official OpenAI host and `max_tokens` elsewhere. Keep JSON mode off unless the chosen model supports it. / 手动配置需同时填写表中输出参数建议；不确定模型是否支持时，保持 JSON 模式关闭。
- Local keyless services require explicit `LLM_ALLOW_KEYLESS=true`. If authentication is enabled, use the service's key and disable keyless mode. Container localhost means the container itself. / 本地免密需明确开启；服务有认证则填写密钥并关闭免密，注意容器回环地址不指向宿主机。

## Custom service / 自定义服务

Choose **Custom service / 自定义服务** for a compatible gateway, a private deployment, or another verified endpoint. Enter its exact API root, one of the three implemented protocols, an accessible model/deployment ID, and the appropriate key. No universal URL or model ID can be supplied for a private deployment. Use that service operator's official documentation.

兼容网关、私有部署或目录外的已核对接口可选择“自定义服务”，自行填写根地址、三类协议之一、账户可用的模型或部署 ID，以及正确的密钥。私有服务没有通用地址或模型名称，需按该服务自己的正式文档配置。

## Azure, Bedrock, and legacy endpoints / 云平台与旧接口边界

**Azure OpenAI / Foundry:** replace `your-resource` in the template with your own resource and use its deployment name as the model ID. The v1 API also supports resource roots ending in `.services.ai.azure.com/openai/v1`. StudyLoop uses the API-key path; it does not refresh Microsoft Entra tokens. The older deployment URL requiring an `api-version` query is not directly supported. [Azure v1 documentation](https://learn.microsoft.com/en-us/azure/foundry/openai/api-version-lifecycle).

Azure 需替换模板中的资源名，模型栏填写部署名称；也可使用官方支持的 `.services.ai.azure.com/openai/v1` 资源格式。当前采用 API Key 接入，不自动刷新 Entra Token；旧版带 `api-version` 的专用路由仍需兼容网关。

**Amazon Bedrock:** the preset uses the documented US East (N. Virginia) `bedrock-runtime` Chat Completions endpoint with a **Bedrock API key**. Use a model available through that endpoint and region. StudyLoop does not perform SigV4 signing, accept an AWS Access Key/Secret Key pair, or send Bedrock-specific guardrail headers. [Bedrock Chat Completions documentation](https://docs.aws.amazon.com/bedrock/latest/userguide/inference-chat-completions-mantle.html).

Bedrock 预设采用美国弗吉尼亚 `bedrock-runtime` 对话接口及 **Bedrock API Key**，并非 AWS Access Key / Secret Key 组合。模型必须在对应地域与接口可用；当前不执行 SigV4 签名，也不发送 Bedrock 专用防护策略请求头。

The directory does not include these as new-user presets:

- **01.AI / 零一万物:** its official platform announced API shutdown at 24:00 on 2026-09-03. / 官方公告已于该时间停止 API 服务。[Official platform / 官方公告](https://platform.lingyiwanwu.com/).
- **Legacy Hunyuan / 旧混元平台:** new purchases have stopped and the platform is moving to TokenHub; the notice allows existing purchased services to continue for now. / 新用户使用 TokenHub，不把旧入口标为全面停服。[Migration notice / 迁移说明](https://cloud.tencent.com/document/product/1729/111007).
- **Legacy LKEAP DeepSeek / 旧 LKEAP DeepSeek:** official guidance directs users to TokenHub. The separately documented third-party v3 interface can still be configured as a custom service with its own key. / DeepSeek 功能迁移至 TokenHub，独立第三方 v3 接口按其专用密钥自定义配置。[Official guidance / 官方说明](https://cloud.tencent.com/document/product/1772/128806).
- **Tencent TI-ONE / 腾讯 TI-ONE:** URLs, service-group model IDs, and authentication depend on the deployment; some gateways use a raw AuthToken rather than Bearer. / 无统一预设地址，原始 AuthToken 鉴权不适配当前 Bearer 客户端。[Service invocation / 调用说明](https://cloud.tencent.com/document/product/851/74142/).
- **Baichuan / 百川:** indexed official documentation describes a compatible interface, but current new-account access and model parameters were not confirmed. / 未确认当前新账户权限与模型参数，暂不列为可直接使用的预设，不据此判断停服。[Official API documentation / 官方文档](https://platform.baichuan-ai.com/docs/api?activity=true).

Other proprietary protocols, required custom headers, and subscription-only coding endpoints are not automatically supported by a shared model brand. Use an explicitly compatible endpoint or gateway.
